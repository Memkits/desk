结论先行

方解石（CaCO₃）几乎所有显眼的性质，都能追到同一个结构事实：平面三角形的碳酸根，全部平行地排成垂直于 c 轴的层，层与层之间由 Ca²⁺ 的离子键连接。 碳酸根内部是强的共价键（C–O 1.28 Å），组与组之间是较弱的 Ca–O 离子键（2.36 Å）。

原子与成键

方解石由两种结构单元组成：球形、容易去掉两个电子的 Ca²⁺，和一个平面三角形、带两个负电荷的 CO₃²⁻。前者决定了离子键的部分，后者决定了各向异性。

钙离子。 Ca 的电子排布是 [Ar] 4s²。两个 4s 电子脱离后留下稳定的氩型闭壳层，电子云是球对称的，而且很“硬”：极化率小，对光的响应几乎各向同性。它在晶体里主要提供正电荷和离子键。

碳酸根。 中心的 C 取 sp² 杂化，与三个 O 形成三个 σ 键，键角严格 120°（在方解石里由三次对称轴保证）。C 剩下的一个 p 轨道垂直于平面，和三个 O 的 p 轨道组成离域的 π 体系。用共振的语言说，有三个等价的结构，每个里只有一个 C=O 双键；实际的分子是三者的平均，每个 C–O 键级为 1⅓，每个 O 带约 −⅔ 的负电荷。

为什么这个形状很重要。 电子云在一个平面里铺开，外加电场沿平面方向时，电子可以在三个 O 之间大幅移动；电场垂直于平面时，移动空间小得多。三个 O 又互相极化：一个 O 被极化后产生的偶极场，会在平面内加强邻近 O 感受到的电场，在垂直方向则削弱。这就是 W. L. Bragg 1924 年解释双折射的出发点（见“双折射与光学”）。

同一条线索的旁证。 C.V. Raman 1926 年指出：含平面 CO₃、NO₃ 基团的晶体（碳酸盐、硝酸盐）普遍强双折射，而含四面体 SO₄ 的硫酸盐双折射很弱——四面体的电子云近乎各向同性。

晶体结构

方解石可以想象成一个沿体对角线压扁的食盐结构：Ca 占 Na 的位置，CO₃ 占 Cl 的位置，那条体对角线就是 c 轴（也是光轴）。因为 CO₃ 是平的，立方对称被打破，只剩下绕 c 轴的三次对称。

层状排列。 沿 c 轴，Ca 层和 CO₃ 层交替。同一层的 CO₃ 朝向完全一致，相邻两个 CO₃ 层旋转 60°（对三角形等于反向），这就是空间群里的 c 滑移面。加上菱面体平移，六方晶胞的 17.06 Å 里有 6 个 CO₃ 层，层间距约 2.84 Å。

配位。 每个 Ca 被 6 个 O 包围，这 6 个 O 来自 6 个不同的 CO₃ 组（上层 3 个、下层 3 个），组成稍沿 c 轴拉长的八面体。每个 O 一边连 C（共价），一边连两个 Ca（离子）。

与文石的对比。 同样是 CaCO₃，文石是正交 Pmcn（a = 4.959、b = 7.968、c = 5.741 Å，Z = 4），Ca 是 9 配位（Ca–O 平均 2.528 Å），密度 2.93 g/cm³。文石是高压稳定相，地表下亚稳，约 300 °C 以上几天内转变为方解石。它的 CO₃ 也大致平行，所以同样强双折射（双轴负光性，nα 1.530、nβ 1.681、nγ 1.685）。

高压相变。 约 1.5–1.7 GPa 时方解石 I 转为 II，这是位移型相变：CO₃ 组旋转、Ca 微移，密度增加约 2.2%；约 2.0 GPa 处再转为方解石 III（Suito 等 2001）。

双折射与光学

方解石是常见矿物里双折射最强的之一：电场垂直于 c 轴时折射率 1.658，平行于 c 轴时只有 1.486，差 0.172。透过一块解理菱面体看字，会看到两个像。

微观成因。 折射率反映光的电场能把材料里的电子云推动多少（极化率）：推得越动，波走得越慢，n 越大。方解石里的电子主要在氧上，而所有 CO₃ 三角形都平行于同一个面。

  • 电场在三角形平面内（⊥ c）：电子云容易沿平面移动，三个 O 的偶极又互相加强，极化大 → nₒ = 1.658。
  • 电场沿 c 轴：电子云只能离开平面一点，三个 O 的偶极互相削弱，极化小 → nₑ = 1.486。
  • 因为所有 CO₃ 都平行，每个基团的各向异性直接叠加；如果它们随机朝向，就会抵消成各向同性。
  • W. L. Bragg 1924 年（Proc. R. Soc. A 105:370）把每个 O 当作点偶极子，对晶格求局域场之和，定量算出了方解石和文石的主折射率。具体计算值未能核对原文，视频里只讲机制。
  • 从色散看，方解石的折射率可以用几个紫外吸收振子拟合（1535、1000、500 Å），双折射主要来自 1535 Å 振子的强各向异性（Ramachandran 1947）。

波光学。 寻常光（o 光）的电场垂直于主截面（光轴与传播方向所在的平面），始终是 nₒ；非常光（e 光）的电场在主截面内，折射率随方向变化：

\frac{1}{n_e(\theta)^2} = \frac{\cos^2\theta}{n_o^2} + \frac{\sin^2\theta}{n_e^2}

惠更斯作图里，o 光的子波是球面，e 光的子波是扁球（在光轴方向与球面相切）。e 光的能流方向偏离波矢，最大走离角 6.26°（波矢与光轴成 41.9° 时，推算）。光垂直射入解理面时，光轴与法线成 44.6°，走离角 6.23°，两束出射光平行、间距约为厚度的 0.109 倍；e 像沿主截面、朝钝角方向偏移，转动晶体时它绕 o 像转圈。光轴就是穿过两个钝角顶点（三个 101.9° 面角交会处）的方向。

力学

力学性质的关键是两类键的强弱差：C–O 共价键很强，几乎不变形；Ca–O 离子键较弱，变形和断裂都发生在这里。

解理。 在三个方向上完全解理，面与面夹角 74°55′（另一侧 105°05′），破碎后总是菱面体。解理面在形态学标记里是 {10-11}，在结构晶胞里是 {10-14}，即表面科学里常说的 (104) 面。

  • 这个面穿过 CO₃ 组之间，只切断 Ca–O 离子键，不切断任何 C–O 共价键。
  • 面上同时有 Ca 和 CO₃，整体电中性、无极性。
  • DFT 算得表面能约 0.57 J/m²（文献值 0.59），是所算表面里最低的。
  • 对比垂直于 c 轴的 (001) 面：它只含 Ca 或只含 CO₃，是极性面，能量高，所以不解理。

硬度。 莫氏 3，就是莫氏硬度表里 3 的定义矿物，铜片能划动。硬度有各向异性（Taylor 1949，维氏，50 g 载荷）：垂直光轴的面 105，平行光轴的面 145，解理面 136。

弹性。 单位 GPa，Chen 等 2001（布里渊散射）：

C₁₁ 是沿层内方向压缩的刚度，C₃₃ 是沿 c 轴的刚度。层内有 CO₃ 的共价骨架在抵抗，跨层只有 Ca–O，所以前者大了近一倍。

机械孪晶。 受剪切时，方解石容易在 {01-18}（形态学 {01-12}，即“e 孪晶”）上形成孪晶，临界分切应力约 10 MPa。分子动力学显示它的机制是 Ca 的小位移加上 CO₃ 组的协同旋转。地质学家用岩石里方解石孪晶的方向和密度反推古应力。

密度。 2.71 g/cm³，比石英（2.65）稍大，比文石（2.93）小。

化学、热学与光谱

这一组性质都围绕碳酸根：它作为一个整体振动、摆动，接受质子，高温下分解出 CO₂。

遇酸起泡。 CaCO₃ + 2H⁺ → Ca²⁺ + H₂O + CO₂↑。CO₃²⁻ 是弱酸（碳酸）的根，容易接受 H⁺ 变成 H₂CO₃，再分解成水和 CO₂。野外用 5% 稀盐酸区分方解石和白云石：方解石块体就明显起泡，白云石要磨成粉末才起泡。

溶解与岩溶。 25 °C 时 log Kₛₚ = −8.48，即 Kₛₚ ≈ 3.3×10⁻⁹（Plummer & Busenberg 1982）。水里溶了 CO₂ 以后，CaCO₃ + H₂CO₃ → Ca²⁺ + 2HCO₃⁻，溶解度大增，这就是溶洞的来历；反应逆向（CO₂ 逸出）则沉积出石钟乳。方解石的溶解度随温度升高而下降（逆溶解度）。

热分解。 CaCO₃ → CaO + CO₂，ΔH° = +177.8 kJ/mol。平衡 CO₂ 压力可以写成 P ≈ 4.083×10⁷·exp(−20474/T) atm，达到 1 atm 约在 1168 K（约 895 °C，推算）；工业煅烧通常在 900–950 °C。

热膨胀的各向异性。 室温附近，平行 c 轴 +25.6×10⁻⁶/°C，沿 a 轴 −3.7×10⁻⁶/°C，而且 a 轴一直到 900 °C 都是负的（Rao 1968，Markgraf & Reeder 1985）。原因：加热时 CO₃ 绕三次轴的摆动变大，层内方向的平均投影变短；同时 CaO₆ 八面体变大（Ca–O 平均约 15.9×10⁻⁶/°C），把层间撑开。热导率也各向异性：∥c 5.53、⊥c 4.65 W/(m·K)（273 K）。

R-3c 有对称中心，所以拉曼活性和红外活性互斥：ν₁ 只在拉曼谱里强，ν₂ 只在红外谱里出现。同一个对称中心也让方解石没有压电性（对比石英）。

荧光与颜色。 纯方解石无色透明。颜色和发光来自杂质：Mn²⁺ 是主要激活剂，阴极发光峰在 580–640 nm（橙红），低于 1 ppm 就能检出，Fe²⁺ 会猝灭发光；在紫外灯下可发红、蓝、黄等荧光。

上集 · 从原子到双像

  1. 开场：一块解理菱面体压在文字上，字变成两个；转动晶体，一个像绕另一个转。引出问题：这是原子层面的哪个事实造成的？（3D 渲染的透明菱面体 + 光线追踪）
  2. 钙离子：电子壳层从内到外亮起，两个 4s 电子离开，留下球对称、紧致的闭壳电子云（径向密度曲线 + 二维密度图）。
  3. 碳酸根：sp² 杂化轨道展开成 120°，与三个 O 形成 σ 键；垂直的 p 轨道连成离域 π 云；三个共振结构轮流闪现，最后叠成键级 1⅓、每个 O 带 −⅔ 的平均图。展示电子密度的等值面：一张“扁平的饭团”。
  4. 从食盐到方解石：NaCl 立方晶格出现，沿体对角线压扁，Cl 替换成平放的 CO₃，Na 替换成 Ca；体对角线变成 c 轴。（3D，真实坐标）
  5. 层与配位：沿 c 轴层层堆叠，相邻两层 CO₃ 旋转 60°；放大一个 Ca 的八面体配位；六方晶胞（5.0 × 17.1 Å）与解理菱面体的关系。
  6. 极化：光的电场来回振荡，分别沿平面内和沿 c 轴；电子云的位移大小不同；三个 O 的偶极箭头互相加强或削弱（Bragg 1924）。得到 nₒ = 1.658、nₑ = 1.486。
  7. 两种波：折射率椭球；惠更斯子波（球面与扁球）在晶体里传播；一束光垂直射入解理面后分成两束，e 光走离 6.2°；用偏振片分别挡住两个像。（波前的逐帧模拟）
  8. 历史与应用：Bartholin 1669、Huygens 1690、Malus 1808、尼科尔棱镜 1828（o 光在树胶界面全反射的光路动画）、维京太阳石假说。

下集 · 力、热与化学

  1. 开场：一锤下去，碎成的全是小菱面体。
  2. 解理：3D 晶格被 (104) 面切开，只有 Ca–O 键变红断开，CO₃ 完整保留；对比切 (001) 面，得到一面全是正电荷、一面全是负电荷的极性面。三组解理面的夹角 74°55′。
  3. 硬度与弹性：用弹簧模型展示层内（C₁₁ = 149 GPa）与跨层（C₃₃ = 85 GPa）的刚度差；莫氏 3。
  4. 机械孪晶：剪切下 CO₃ 协同旋转、晶格翻转成镜像；地质上的古应力计。
  5. 热膨胀：加热时 CO₃ 绕三次轴摆动变大，层内反而收缩、层间膨胀（带刻度的晶胞动画）。
  6. 分子振动与光谱：ν₁–ν₄ 四种振动的原子动画，对应拉曼与红外谱峰；对称中心导致的互斥规则，以及为什么没有压电性。
  7. 遇酸与岩溶：H⁺ 靠近 CO₃、结合、分解出 CO₂ 气泡；溶洞与石钟乳的反应循环。
  8. 热分解：加热到约 900 °C，CO₂ 离开，留下 CaO；平衡压力随温度的曲线。
  9. 杂质与发光：Mn²⁺ 替换 Ca²⁺，橙红色阴极发光。
