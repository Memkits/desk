# 月球拖船 · 可行性核算

由 `feasibility.py` 生成。常数取自 NASA 行星数据、IAU 2015 标称值和 CODATA 2018；轨道数据来自推演篇的数值积分 `traj.json`。标注“科幻设定”的条目是方案保留的假设，其余都按已知物理计算。


## 悬停

| 项目 | 结果 | 说明 |
|---|---|---|
| 悬停距离 d = √(GM_月/a) | 110,683 km | 取 a = 4×10⁻⁴ m/s² |
| 月亮视直径（地面上） | 1.91° | 今天 0.53° |
| 潮汐力（相对今天） | 41.9 倍 | ∝ M/d³ |
| 洛希极限（刚体 / 流体） | 9,483 / 18,365 km | 悬停距离远在其外，月球不会被潮汐撕碎 |
| 月球要抵消的地球引力 | 0.0325 m/s² | 加上 a 即为月球需要的推力加速度 |
| 总推力 F | 2.42e+21 N | = (M_地 + M_月)·a = 2.42e+21 N（自洽检查） |
| 地球对月球的潮汐加速度 | 1.0e-03 m/s² | 月面重力 1.62 m/s² 的 6.3e-04 |
| 发动机一旦停机，月球落向地球的时间 | 18 小时 | 所以两次点火之间必须改成绕地球的轨道 |
| 在悬停距离上的环绕周期 | 4.2 天 | 点火之间的月相变化周期 |
